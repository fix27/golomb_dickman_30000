# Проверки комплекта

Все проверки собраны здесь и работают из любой папки: корень комплекта
находится автоматически по файлу `golomb_dickman_40000_certified.txt`.

```bash
python checks/run_all.py          # быстрый набор, ~2 минуты
python checks/run_all.py --full   # плюс полный перебор простых усечений, ~5 минут
python checks/run_all.py --arb    # плюс аудит в Arb (нужен python-flint)
python checks/run_all.py --all    # всё сразу
```

Нужен только Python 3.11+ и стандартная библиотека; `python-flint` требуется
лишь для `verify_checkpoints_arb.py`.

## Уровни

| Файл | Что проверяет | Время |
|---|---|---|
| `verify_40000.py` | сертификат, файл цифр, b-file, префикс OEIS; ширина интервала | секунды |
| `verify_checkpoints.py` | все 1 209 чанков: структура, покрытие `[-K_L, K_R]`, точные целые суммы `Lsum`/`Hsum`, концы сертификата | ~1 мин |
| `verify_nodes_decimal.py --methods` | три независимые формулы для $E_1$ (ряд, цепная дробь Стилтьеса, асимптотика) | секунды |
| `verify_nodes_decimal.py --plan` | $M$, $B_{\rm disc}$, $\tau_R$, $\tau_L$ заново и поправки $B$, $TR+TL+B$ | минуты |
| `verify_nodes_decimal.py --chunks N` | `N` чанков пересчитаны заново, сверка 100 знаков с сохранённым интервалом | ~1 мин |
| `verify_mathworld.py` | все утверждения страницы MathWorld «Golomb-Dickman Constant Digits» | ~10 с (перебор до 3000 знаков — ~3 мин) |
| `verify_checkpoints_arb.py` | полный пересчёт узлов в шаровой арифметике Arb | минуты–часы |

## Что именно проверяется у MathWorld

`verify_mathworld.py` разбирает страницу на отдельные утверждения и
сопоставляет каждому статус `PASS`, `FAIL`, `NOTE` (историческое или открытое
утверждение, не проверяемое машинно) или `SKIP` (проверяемо, но не при
текущем пределе).

Проверяются: разложение $0.6243299885\ldots$ и совпадение с OEIS A084945;
1-базная нумерация позиций; последовательность Эрлса A225242; простые
усечения A174974/A174975 вместе с исчерпывающим перебором до 3000 знаков;
первые вхождения цифр A229195; покрытие всех строк длины 1, 2, 3; отсутствие
`0123456789` и `9876543210`; таблица частот цифр для 10, 100, 1000 и 10 000
знаков.

Исторические утверждения (Митчелл, 1968; 15 000 знаков Вайсштейна, 2013;
таблица первооткрывателей) помечены `NOTE`: цифры с ними согласуются, но
сами атрибуции машинной проверке не поддаются. Утверждение о завершённом
переборе до 15 000 знаков помечено `SKIP`: полный перебор до 15 000 знаков
занял бы часы, по умолчанию перебор идёт до 3000.

## Почему в корне остались копии скриптов

`verify_40000.py`, `verify_checkpoints.py`, `verify_checkpoints_arb.py` и
`verify_nodes_decimal.py` лежат и в корне комплекта: это опубликованные
точки входа, и их контрольные суммы зафиксированы в `SHA256SUMS.txt`.
Копии здесь — рабочая версия, которая сама находит корень комплекта; они
ничем не отличаются по логике, только определением пути по умолчанию.

## Контрольные суммы

```bash
sha256sum -c checks/SHA256SUMS.txt
```
