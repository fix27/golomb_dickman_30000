# golomb_dickman_30000
The Golomb–Dickman constant (OEIS A084945) was computed to 30,000 decimal digits using interval arithmetic (FLINT/Arb) and Takahasi–Mori quadrature with 186,661 nodes. Three methods evaluated $E_1$ to avoid accuracy loss; the result matches an independent Python implementation and OEIS data, with certification via ball radius $10^{-30058}$.
